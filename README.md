# Group-Project-2025-2026

# Description
University Recycle Zone is a collection monitoring system designed for campus-wide sustainability. The system tracks the collection of recyclable materials by managing the quantity, mass, and location of every transaction. It bridges the gap between waste contributors (students/departments) and system administrators to ensure data-driven recycling management. By digitizing the traditional manual logging process, the system provides a centralized platform for environmental accountability within the university ecosystem.

# Features
- User Frame for Students
- Add and View Contribution on Users
- Weekly Column Chart
- Admin Login
- Admin Frame for Authorized Personnel
- Records Table and Student Table on Admin
- CRUD Operation on Admin
- Dashboards on Admin
- Bin Status

# Technologies used
- Netbeans
- JavaSwing
- XAMPP
- Microsoft SQL

# Setup/Installation guide
We installed and used NetBeans to develop our system. Java Swing was utilized to design and build the graphical user interface. The development environment was configured to ensure all necessary libraries and dependencies were properly set up. This setup allowed us to efficiently create, test, and run the application. For our database, we used XAMPP and Microsoft SQL. These tools were utilized to create and manage the database structure. They were also configured to establish a stable connection with our system.
